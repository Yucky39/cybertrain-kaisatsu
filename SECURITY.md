# Security policy

cybertrain-kaisatsu is pre-alpha and has not had an independent security review.

## Reporting a vulnerability

Please report vulnerabilities through GitHub's Private Vulnerability
Reporting (this repository's Security tab → "Report a vulnerability"), not
in a public issue.

In scope: the library (`cybertrain/kaisatsu/`) and the code `kaisatsu install`
generates into an application: password hashing, tokens, sessions, the
sign-in limits, and the password-reset and email flows.

We aim to answer within 7 days. Please give us time to ship a fix before you
publish the details.
